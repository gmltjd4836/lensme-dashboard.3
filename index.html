지도 연결

기존 코드의 지도 키를 기본 적용했습니다. 카카오 개발자 설정에 현재 사이트 도메인이 등록돼 있어야 합니다.

무료 한도 관리를 위해 전국 시설을 자동 수집하지 않습니다. 선택한 상권만 수집하며 한 번의 수집 요청 수에 상한을 둡니다.

자료 가져오기

선택된 상권에 CSV 또는 JSON 자료를 추가합니다. CSV 열 이름과 예시는 아래 양식을 사용하세요. 대한민국 WGS84 경위도 좌표를 사용합니다.

상권을 선택해주세요.

공공 상가 CSV의 상호명·위도·경도·상권업종중분류명도 인식합니다. 자료는 선택 상권 주변 500m 범위로 걸러 저장합니다.

모델 기준

도로 연결망의 최단 보행경로, 보행거리 내 시설, 접근성과 교차로 구조를 조합합니다. 자동 도로 후보는 점포 출입구가 아닙니다.

백업과 기존 자료

기존 V59 백업의 areas·geometry·path를 인식합니다. 과거 TOP3는 새 기준과 달라 이관하지 않습니다. 같은 이름의 다른 상권은 유지하고 동일 경계의 중복은 건너뜁니다.

브라우저 저장소는 계정 동기화가 아닙니다. 여러 직원의 동시 수정은 지원하지 않습니다. 새 기기에는 백업 파일을 가져오세요.
